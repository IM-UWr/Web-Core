Regulations of the Mathematical Institute local computer network

Rules for using the computer network and the Computer Laboratory of the Mathematical Institute, University of Wrocław.

Every user of the Computer Network and the Computer Laboratory of the Mathematical Institute, University of Wrocław, is bound by:

  1. the Polish Criminal Code, Chapter XXXIII “Offences against the protection of information” (Journal of Laws 1997 No. 88 item 553);
  2. the regulations of the University of Wrocław, in particular Rector’s Order No. 142/2017 on the security of information processed in IT systems and the rules for using the IT infrastructure of the University of Wrocław (Polish);
  3. the Regulations of the Computer Network and the Computer Laboratory of the Mathematical Institute, set out below.

Introduction

These regulations apply to all users of the computer systems maintained by the Computer Laboratory of the Mathematical Institute.

General provisions

  1. A user may use the resources of the Institute network only after an account has been created, i.e. after being assigned a user name (login name) and a password. Being assigned a user name also obliges the user to read and comply with these regulations.
  2. The right to use the resources of the Institute network is granted by the Dean of the Faculty.
  3. The Head of the Laboratory is responsible to the Dean for the proper functioning of the Institute network.
  4. Administrators have the right to verify the identity of persons using the resources of the Institute network.
  5. The user is responsible for all operations performed using the account assigned to them, as well as for any damage or unlawful activity carried out using their account.
  6. During classes the teacher is responsible for discipline in the computer lab; at other times, the network administrators.
  7. During classes only students taking part in those classes according to the timetable may be present in the lab; other users only if the teacher agrees before the class begins.
  8. Outside class hours users may use the computer laboratory during the working hours of the network administrators.

Rights and obligations of the user

  1. The user has the right to privacy of the data stored in the resources of the Institute network.
  2. The Computer Laboratory will make every effort to ensure the security of user data.
  3. The user must protect access to network resources by choosing a sufficiently strong password. If the user finds that the account has been used by other persons, they must notify the administrator immediately. The same applies if the user finds that they have access to more than one account.
  4. The user must follow the administrator’s instructions concerning the technical conditions of using the systems.
  5. The user must strictly comply with all licence terms of the software owned by the Mathematical Institute.
  6. After finishing work in the computer laboratory under Windows, the user must leave the computer switched to the Linux login option.
  7. Any failures or malfunctions of the network or equipment noticed must be reported promptly to a member of the laboratory staff.
  8. The user is financially liable for any damage to computer equipment resulting from its improper use.

The user should avoid any actions that hinder the work of other users of the system. This means, among other things:

  • taking care of the computer equipment placed at their disposal,
  • using the occupied main memory economically,
  • using processor time economically,
  • using shared disk space (e.g. /tmp) economically.

Prohibitions

  1. An account in the Institute network may be used only by the person to whom it was assigned. Sharing an account or its password with another person will result in the account being blocked immediately.
  2. Using the equipment or software made available to users for commercial purposes is prohibited.
  3. It is forbidden to install and run software that compromises the security of the system and of other users, in particular viruses, programs monitoring network traffic, programs breaking existing security measures, etc.
  4. It is forbidden to install and run, without the administrator’s permission, any software that overuses the resources of the Institute network (memory, processor) and thus infringes the rights of other users, especially during classes.
  5. Copying programs made available in the computer systems and owned by the Faculty is prohibited.
  6. Using one’s own web page to distribute content that is contrary to Polish law is prohibited.
  7. It is forbidden to disconnect workstations in the computer rooms from the wired network. Laptops may be connected to the wireless network.
  8. It is forbidden to change the configuration of a computer.
  9. Eating and drinking in the computer laboratories is prohibited.

Sanctions

Users who violate these regulations are subject to the sanctions provided for in Polish law and the disciplinary sanctions set out in the Regulations of the University of Wrocław. For actions contrary to these regulations, the Dean of the Faculty may:

  • restrict the user’s rights to the resources of the Institute network,
  • temporarily suspend the user’s right to use the systems,
  • withdraw the right to use the systems.
